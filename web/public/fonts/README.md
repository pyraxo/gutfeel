# Bricolage Grotesque

The website headings use Bricolage Grotesque by Mathieu Triay and the project
contributors. The bundled font uses weight 800 and is served locally.

- [Font project](https://github.com/ateliertriay/bricolage)
- [Google Fonts source and license](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque)
- License: SIL Open Font License 1.1, included in [OFL.txt](OFL.txt).

The unmodified TTF was obtained from the Google Fonts CSS API for
`Bricolage Grotesque:opsz,wght@12..96,800`.
